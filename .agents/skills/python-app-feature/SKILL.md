# Python app feature
1. Find the existing entry point, code conventions, and external contract; do not redesign unrelated systems.
2. State the smallest interface change that meets acceptance criteria.
3. Implement input validation, failures, clear behavior, and appropriate type hints.
4. Use existing libraries. Add dependencies only with a reason and project permission.
5. Add targeted unit/integration tests; verify expected and error flows.
6. Run project lint, format, and appropriate tests; do not claim checks that were not run.
7. Report changed files, commands, test result, and one actionable caveat (if any).
